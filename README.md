# Explain Concepts｜概念與知識講解

讓 AI 介紹新知識時，先建立完整概念，再深入原理與實際應用，最後連結目前專案。

## 為什麼建立這個 Skill？

當我們在開發專案時詢問「什麼是 Tiptap？」這類問題，
AI 經常只介紹與目前專案有關的功能。

這有助於完成眼前的任務，卻容易讓我們忽略：
- 這項技術原本要解決什麼問題？
- 除了目前專案，它還有哪些用途？
- 它如何運作，實際上該怎麼使用？
- 它有哪些限制，什麼情況適合採用？

這個 Skill 的目的是讓 AI 同時兼顧知識的廣度、深度與實務，
幫助使用者建立能應用到其他情境的理解。

## 講解方式

| 面向 | 講解內容 |
| --- | --- |
| 概念定位 | 它是什麼、屬於哪一類、為什麼需要它 |
| 應用廣度 | 主要能力，以及不同的使用情境 |
| 核心原理 | 重要組成、彼此關係與運作流程 |
| 實際使用 | 透過完整小案例，說明從需求到結果的過程 |
| 使用邊界 | 適用情況、限制與常見誤解 |
| 專案連結 | 最後說明它在目前專案中扮演的角色 |

核心原則：上下文用來調整講解難度與例子，不應成為縮小知識範圍的理由。

## 使用範例

在支援 Skills 的 AI 工具中安裝後，可以提出：

> 請使用 explain-concepts，介紹什麼是 Tiptap。

> 什麼是執行環境？請解釋原理，並提供不同語言的實際案例。

> 我正在做 AI 專案，請先完整介紹 RAG，再說明它與我的專案有什麼關係。

也可以指定回答範圍：

> 請簡短介紹，只說明基本概念與一個例子。

Skill 會依照使用者明確指定的篇幅與範圍調整回答。

## 如何使用

1. 找到本專案中的 `explain-concepts/SKILL.md`。
2. 依照你使用的 AI 工具所提供的 Skills 安裝方式匯入。
3. 在對話中指定使用 `explain-concepts`，並提出想了解的問題。

如果工具不支援 Skills，也可以將 `SKILL.md` 的指令內容貼入對話，
作為該次講解的規則。
